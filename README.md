## Selected projects

### Demand Forecast Data Platform

[Repository](https://github.com/ibrahim-alohali/demand-forecast-data-platform)

A Python and PostgreSQL pipeline for UCI Online Retail II, organised into raw,
staging, analytical and feature tables, with 11 SQL data-quality contracts and 142
tests that GitHub Actions runs against PostgreSQL. It forecasts the next day's
recorded sales from past observations and compares a linear model with previous-day
and previous-weekday baselines. The repository explains the data exclusions,
evaluation, tests and limitations.

### Cafe Sales Data Quality API (private)

A FastAPI service over 10,000 synthetic cafe transactions. It records a 160,000-row
cell-level audit (raw value, status, provenance and rule), reloads data atomically
and has 224 pytest tests. The repository is private for now; the code is available
on request.
